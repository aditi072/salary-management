# Screens

Angular app for the HR manager. It calls the API on port 8080 through a dev proxy.

From `frontend`, with the API already running:

```powershell
npm start
```

Open http://localhost:4200.

- Directory: search, filter, and page through employees. Open a code to edit that person.
- Add employee: currency is chosen by the country, on the server.
- Pay summary: headcount, total, and average per currency, then by country and department.
